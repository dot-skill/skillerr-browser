# Contributing

Issues and pull requests are welcome.

- **Bugs:** open an issue with what you did, what you expected and what happened (a screenshot helps).
- **Security:** please don’t open a public issue. Email support@skillerr.com (see [SECURITY.md](.github/SECURITY.md)).
- **Pull requests:** open them against `develop` (merging there publishes a beta; `main` is production). Keep them
  focused, match the surrounding code, run `npm test`, and run the app (`npm start`) to check your change.
  Skillerr stays lightweight: no new dependencies without a good reason.
- **Licence:** Skillerr is AGPL-3.0. Your first pull request needs the one-line agreement from [CLA.md](CLA.md).
- **Conduct:** everyone taking part follows the [Code of Conduct](.github/CODE_OF_CONDUCT.md).
- **Name and logo:** see [TRADEMARKS.md](TRADEMARKS.md) if you plan to ship a fork.
